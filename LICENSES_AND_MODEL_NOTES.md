# Model and code licensing notes

This project downloads third-party pretrained checkpoints from upstream Hugging Face repositories at runtime. Review each model card and license before commercial use or redistribution. This ZIP does not bundle pretrained model weights.

- Grounding DINO Tiny: https://huggingface.co/IDEA-Research/grounding-dino-tiny
- DINOv2 Small: https://huggingface.co/facebook/dinov2-small
- Grounding DINO documentation: https://huggingface.co/docs/transformers/model_doc/grounding-dino

The supplied assignment dataset is included for the user's evaluation. Do not redistribute it unless you have permission from its owner.
