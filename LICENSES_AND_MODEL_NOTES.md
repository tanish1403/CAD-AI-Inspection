# Model and code licensing notes

This project downloads third-party pretrained weights from their upstream repositories at runtime. Review the model card and license for each selected checkpoint before commercial use or redistribution. This ZIP does not bundle pretrained model weights.

- Grounding DINO checkpoint: https://huggingface.co/IDEA-Research/grounding-dino-tiny
- DINOv2 checkpoint: https://huggingface.co/facebook/dinov2-small
- SAM2 checkpoint: https://huggingface.co/facebook/sam2-hiera-small
- SAM2 source and installation: https://github.com/facebookresearch/sam2

The supplied assignment dataset is included for the user's own evaluation. Do not redistribute it unless you have permission from its owner.
